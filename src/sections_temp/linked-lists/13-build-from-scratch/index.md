# Building a Linked List from Scratch

Welcome to the ultimate linked list challenge! This comprehensive exercise will guide you through building a complete linked list implementation from the ground up.

## What You'll Build

You'll create a fully functional linked list data structure with all essential operations, implementing each component step by step:

### Core Components
- **Node Factory Function** - Create individual list nodes
- **LinkedList Factory Function** - Main list structure with size tracking

### Essential Operations
- **addToHead** - Insert elements at the beginning
- **addToTail** - Insert elements at the end  
- **removeFromHead** - Remove and return first element
- **removeFromTail** - Remove and return last element

### Advanced Operations
- **contains** - Check if a value exists
- **indexOf** - Find the index of a value
- **removeAt** - Remove element at specific index
- **insertAt** - Insert element at specific index

### Performance Analysis
- **getBigONotations** - Return Big O complexity for all methods

## Implementation Phases

This exercise is structured in 11 progressive phases, each building upon the previous ones:

**Phase 1-2:** Foundation (Node and LinkedList factories)
**Phase 3-6:** Basic operations (add/remove from head/tail)
**Phase 7-8:** Search operations (contains, indexOf)
**Phase 9-10:** Index-based operations (removeAt, insertAt)
**Phase 11:** Performance analysis (Big O notations)

## Key Requirements

- Use **function-based approach** (no classes)
- **Track list size** automatically
- **Handle edge cases** (empty list, invalid indices)
- **Return appropriate values** for each method
- **Maintain proper linking** between nodes

## Learning Objectives

By completing this exercise, you'll master:
- Factory function patterns in JavaScript
- Linked list traversal algorithms
- Edge case handling strategies
- Time complexity analysis
- Memory management concepts

## Why Build from Scratch?

Understanding how to implement data structures from scratch is crucial for:
- **Technical interviews** - Common coding challenge
- **Performance optimization** - Know when and why to use linked lists
- **Algorithm design** - Foundation for more complex structures
- **Problem-solving skills** - Break down complex problems into manageable pieces
