# In-Class Set Exercise

Practice Set operations in a collaborative classroom environment with guided instruction and peer learning.

## Exercise Overview

This in-class exercise provides hands-on practice with Set operations while working alongside your classmates and instructor.

## What You'll Practice

- **Set fundamentals** - Creating and manipulating Sets
- **Membership testing** - Using has() for fast lookups
- **Deduplication** - Removing duplicates from data
- **Set operations** - Union, intersection, difference
- **Real-world applications** - Practical Set usage patterns

## Collaborative Learning

Work with your classmates to:
- Share different approaches to problems
- Debug issues together
- Learn from each other's solutions
- Build confidence with Set operations
