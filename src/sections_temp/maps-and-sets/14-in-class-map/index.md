# In-Class Map Exercise

Practice Map operations in a collaborative classroom environment with guided instruction and peer learning.

## Exercise Overview

This in-class exercise provides hands-on practice with Map operations while working alongside your classmates and instructor.

## What You'll Practice

- **Map fundamentals** - Creating and manipulating Maps
- **Key-value operations** - Setting, getting, and deleting entries
- **Iteration patterns** - Looping through Maps effectively
- **Data organization** - Using Maps for structured data storage
- **Real-world applications** - Practical Map usage patterns

## Collaborative Learning

- Share different approaches to problems
- Debug issues together
- Learn from each other's solutions
- Build confidence with Map operations
