# Learning Objectives: Stacks & Queues

## 🎯 What You Will Learn

This section covers stacks and queues as fundamental data structures for sequence management. By the end of this section, you will understand LIFO and FIFO principles and implement efficient stack and queue operations.

## Data Structure Stack

**Module 5 - Apply Level:**
- Implement code to push a value onto a Stack and know it's runtime
- Build a LIFO Stack without using built-in libraries
- Implement code to pop a value from a Stack and know it's runtime
- Implement code to peek at the top value in a Stack and know it's runtime

**Module 5 - Remember & Understand Level:**
- Explain why Stack operations run in constant O(1) time
- Identify real-world or interview problems where Stack is the ideal data structure
- Compare Stack behavior to Queue behavior and describe differences in use cases

## Data Structure Queue

**Module 5 - Apply Level:**
- Implement code to enqueue a value in a Queue and know it's runtime
- Build a FIFO Queue without using built-in libraries
- Implement code to dequeue a value from a Queue and know it's runtime
- Implement code to peek at the front value in a Queue and know it's runtime

**Module 5 - Remember & Understand Level:**
- Explain why Queue operations (enqueue/dequeue) typically run in constant O(1) time (Linked List) or O(n) (Array)
- Compare performance trade-offs between array-based and linked-list-based Queue implementations
